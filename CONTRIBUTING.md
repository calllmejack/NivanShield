# Contributing

Contributions are welcome through GitHub issues and pull requests.

## Before opening a pull request

1. Do not commit passwords, UUIDs, live subscription URLs, private keys, logs, or `%LOCALAPPDATA%\NivanShield` data.
2. Keep the original SSH host-key/password flow compatible unless a migration path is included.
3. Build with `Build.cmd` on Windows.
4. Test at least one SSH profile and one V2Ray profile through the real internet verification step.
5. Preserve the GPL license and third-party notice files.

Connection logs should be redacted before attaching them to an issue.
