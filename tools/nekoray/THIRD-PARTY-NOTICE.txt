NekoRay / NekoBox for PC 4.0.1 (2024-12-12)
================================================

Nivan Shield 4.1 runs the separately distributed nekobox_core.exe headlessly
as an integrated SSH routing engine. The NekoRay graphical window is not
launched by the default workflow. NekoRay is not authored by the Nivan Shield
project.

Portable package hygiene
------------------------
The Neko core was copied from the user-supplied Windows 4.0.1 portable archive.
The graphical nekobox.exe/Qt runtime, updater, profiles, subscriptions, logs,
and the entire personal config directory are excluded from the 4.1 release.
Nivan Shield creates only a temporary runtime routing config under its own
local application-data directory and removes it on Disconnect.
